## The lore, minus the 47-episode flashback

I’m the **co-founder & CTO at [Blueprint](https://blueprint.io)**, building tools for hardware design.

Before that, I co-founded **3e8 Robotics**, helped build an elevator-riding delivery robot, worked on putting LLMs onto **Rivian** vehicle hardware, and wrote embedded software at **Qualcomm**.

Apparently, “full stack” wasn’t enough. I wanted the stack to have wheels.

My favorite part of engineering is the moment a mysterious black box becomes something I can explain, build, and improve. My second-favorite part is finding out the fix was one line. We do not discuss how long finding that line took.

## My actual superpower: wanting to know how it works

Some people collect sneakers. I collect questions that become weekend projects.

- **Systems:** What is the computer *actually* doing underneath the abstraction?
- **AI:** Can this model run somewhere smaller, cheaper, or more interesting than a giant server?
- **Robotics:** What happens when your software can physically bump into the problem?
- **Developer tools:** Can we make the next person’s debugging session less of an archaeological expedition?

## Side quests that escaped the notes app

### 🥷 [Chronicle](https://github.com/pseelam02/chronicle#readme)

A local-first Git time machine for TypeScript: architecture maps, symbol lineage, historical comparisons, and change-risk analysis.

For when `git blame` gives you a name, but you were hoping for an explanation.

**TypeScript · Node.js · React · Git · AST analysis**

### 🤖 [Elly](https://pseelam.com/projects/)

An autonomous indoor delivery robot that rides elevators across multiple floors. Real-world autonomy, safety-first state machines, and remote-ops fallback.

The robot can press the elevator button. We are one step closer to automating awkward elevator small talk.

**Python · ROS · SLAM · WebRTC**

### 🪶 [Feather](https://www.feather.cv/)

An AI-powered LaTeX resume editor with live PDF previews and editing tools.

Because “aligned a bullet point in LaTeX” should count as work experience.

**Next.js · TypeScript · LaTeX · OpenAI**

### 📚 [NanoGPT-Shakespeare](https://pseelam.com/projects/)

A character-level Transformer built from first principles: attention, causal masking, training, and autoregressive generation.

To overfit, or not to overfit. That is the validation loss.

**Python · PyTorch · Transformers**
